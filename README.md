# Credit Scoring : Probabilité de Défaut (PD)

Modèle de scoring crédit . Prédit la probabilité qu'un client fasse défaut sur un crédit dans les 2 prochaines années.

---

## Dataset

[Give Me Some Credit](https://www.kaggle.com/c/GiveMeSomeCredit) Kaggle  
150 000 clients, 6.7% de défauts

---

## Résultats

| Métrique | Score |
|----------|-------|
| AUC | 0.8678 |
| Gini | 0.7357 |
| Recall (défaut) | 0.77 |

---

## Stack

Python, XGBoost, Scikit-learn, Pandas, Matplotlib
